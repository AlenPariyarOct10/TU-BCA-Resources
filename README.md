# BCA Study Archive

A carefully organized collection of BCA notes, semester materials, exam preparation files, project resources, routines, documents, and event media.

This repository is meant to be a quick place to browse academic resources by semester, keep important documents together, and preserve useful college materials in one clean archive.

## Suggested Use

Use the semester folders when looking for subject-specific materials. Use [BCA - Docs](BCA%20-%20Docs/) for general documents, and visit [Events](Events/) for media, presentations, and event-related files.

## Repository Care

To keep this archive useful:

- Add new resources to the correct semester or topic folder.
- Use clear file names whenever possible.
- Keep duplicate files to a minimum.
- Store event files inside [Events](Events/) instead of semester folders.
